# agent-learning-guide

> **分类**：原创 / AI 打磨 ｜ **文件数**：5 ｜ **仓库目录**：`agent-learning-guide`

## 📌 简介

一份 **Agent 学习资料集**，两份核心文档覆盖「背诵级速记」与「逐行代码精读」两个层次：

| 文档 | 定位 | 适合谁 |
|---|---|---|
| `Agent专家必背清单.md` | **速记手册**：按背诵优先级分级（P0 必须脱口而出 / P1 必须熟练讲清 / P2 理解即可） | 面试前突击、需要对外讲清楚 Agent 概念的人 |
| `Agent长文本逐代码详解.md` | **逐行精读**：把一段长文里的 Agent 代码逐行拆开讲 | 第一次真正读 Agent 代码的人 |

配套 `LICENSE` 与 `.gitignore`，克隆即读，无任何依赖。

## 🎯 适用场景

- 准备 **Agent / LLM 应用方向面试**，需要一套能脱口而出的概念框架
- 对外做分享，需要把「Agent 是什么、怎么跑起来」讲得有条理
- 第一次读 Agent 代码，被一大段长文本劝退，想要逐行拆解
- 团队新人入职培训的预习材料

## ✨ 内容亮点（摘自必背清单）

### Agent 的一句话定义（P0，专家第一句）

> **Agent = LLM（大脑）+ 工具生态（手脚）+ 记忆系统（经验沉淀）+ 规划引擎（策略制定）**

传统 LLM 给建议，Agent 做事情。Agent 具备
**目标拆解 → 资源调用 → 结果落地** 的全流程闭环能力。

### 三大自主能力（P0）

| 能力 | 含义 |
|---|---|
| 自主感知 | 理解当前环境和任务需求 |
| 自主决策 | 制定执行计划并动态调整 |
| 自主执行 | 调用工具完成实际任务 |

### ReAct 循环（P0，全文之魂）

必背清单里要求**能默写 ReAct 的提示词骨架**——
这是整套资料里最核心的一条，其余内容基本都围绕它展开。

## 🧭 两份文档详解

### `Agent专家必背清单.md`

- **分级背诵**：P0（必须脱口而出）/ P1（必须熟练讲清）/ P2（理解即可，被追问时能展开）
- 开篇即给一句话定义与三大自主能力，避免「Agent 就是个会调工具的 AI」这种含糊说法
- ReAct 循环给到**提示词骨架**级别，要求能默写
- 适合做成闪卡或睡前过一遍

### `Agent长文本逐代码详解.md`

- 针对一段较长的 Agent 实现代码，**逐行拆开讲**
- 每一段都解释「这行在整体流程里扮演什么角色」，而不是孤立解释语法
- 适合配合一段你正在读的 Agent 源码对照着看

## ❓ 常见问题

**Q：需要先会某个框架（LangChain / LangGraph）吗？**
不需要。资料刻意**框架无关**，先讲清楚 Agent 的通用组成与 ReAct 循环，
框架只是这些概念的工程化实现。

**Q：文档里的代码能直接跑吗？**
逐行详解那篇是**教学用拆解**，不是可运行的完整项目。它的价值在于讲清每一行为什么存在。

**Q：会更新吗？**
Agent 生态变化很快，这两份覆盖的是**不随框架变化的核心概念**——
这部分是最经得起时间考验的。
